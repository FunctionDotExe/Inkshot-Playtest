# Inkshot: The Last Show

**Play the November 18 browser build.** Download the latest ZIP, extract it, and follow `PLAY.txt` to serve it locally. Open the local address in your browser and enter the existing playtest password. Each release includes its changes and a SHA-256 checksum. [Download the latest playtest](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/latest)

The hosted browser version uses the same playtest password. For November 18 co-op, have everyone use the downloadable build above. [Hosted browser game](https://inkshot.rubenm.me/)

**Co-op.** Everyone needs the same build. The current browser playtest uses protocol 147. The host creates a co-op room and shares the code. After everyone joins, the host can select **Start Rehearsal Together** to play Chapter Four without campaign unlocks. Everyone confirms their own weapon, and play starts after the final confirmation. The host chooses the difficulty and Director’s Notes. Co-op requires internet access.

**Earlier Windows build.** The November 15 Windows release uses protocol 145 and can play with that same Windows release. It cannot join the current browser build. A new Windows executable remains on hold while a native antivirus alert is unresolved. [November 15 Windows release](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/tag/redesign-2026-11-15)
