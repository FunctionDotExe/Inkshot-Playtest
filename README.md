# Inkshot: The Last Show

**Download for Windows x64.** Get the November 18 ZIP, extract the whole folder, and open `Inkshot - The Last Show.exe`. Keep its Data folder, DLLs and runtime folders together. The release includes a SHA-256 checksum for the ZIP. [Download the latest Windows build](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/latest)

**Play in your browser.** Enter your playtest password and choose Chapter Four, then Rehearsal, for Zombie Loot. On a MacBook, the [Performance launch](https://inkshot.rubenm.me/?performance=1) keeps the drawing buffer at up to 720p. [Play Inkshot](https://inkshot.rubenm.me/)

**Co-op.** Everyone should use the same release. For Chapter Four Zombie Loot, open the website on every Mac or Windows PC in the party (protocol 152). The November 18 Windows download plays with other copies of that download (protocol 147). The host creates a co-op room and shares the code. After everyone joins, the host can select **Start Rehearsal Together** to play Chapter Four without campaign unlocks. Each player confirms their own weapon, and the game starts after the final confirmation. The host chooses the difficulty. Co-op requires internet access.

The November 15 Windows build uses protocol 145. Use that same Windows release for everyone joining its rooms. [November 15 Windows release](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/tag/redesign-2026-11-15)
