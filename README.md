# Inkshot — The Last Show

[Download the latest Windows build](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/latest) · [Play the browser version](https://inkshot.rubenm.me/)

Download the ZIP from the latest release, extract the entire folder, and open **Inkshot - The Last Show.exe**. Keep its Data, DLL and runtime folders together. No installer is required.

For co-op, all players must use the same current release. The host creates a room and shares its code; other players join and finish their loadout before the host starts. Internet access is required.

The November 14 browser update uses co-op protocol **145**. The latest Windows download is the October 26 release, using protocol **117**; these versions cannot join each other's rooms. For the updated co-op game, both players should use the browser version. Windows players can still play together using the same October 26 release.

The browser version uses the existing website password. Build identity, changes and verification details are listed in each release.

This repository distributes compiled playtest builds. The ZIP in the repository file list is historical; use **Releases** for current downloads.
