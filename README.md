# Inkshot: The Last Show

[Download the latest Windows build](https://github.com/FunctionDotExe/Inkshot-Playtest/releases/latest) | [Play the browser version](https://inkshot.rubenm.me/)

**Windows:** download the ZIP from the latest release, extract the whole folder, and open **Inkshot - The Last Show.exe**. Keep its Data, DLL and runtime folders together. No installer is needed.

**Browser:** open https://inkshot.rubenm.me/ and enter the website password.

**Co-op:** every player needs the current release. The latest Windows release and the website are built from the same source (protocol 145). The host creates a room and shares its code; the others join and finish their loadout before the host starts. You need internet access.

Each release lists its build identity and changes. This repository distributes compiled playtest builds. The ZIP in the file list is an old build; get current downloads from **Releases**.
